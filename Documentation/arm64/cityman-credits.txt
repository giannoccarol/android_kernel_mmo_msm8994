Lumia 950 XL (cityman) kernel: credits
======================================

This branch (lineage-18.1-cityman-rom) is the Android4Lumia950 commonized
MSM8994 kernel with Lumia 950 XL changes on top. Work from others that it
uses, and where it comes from:

Base
----
- Android4Lumia950 (djokcho, EpicLPer, j0sh1x and the community):
  android_kernel_mmo_msm8994, the talkman/cityman device trees, the
  charging, USB and Bluetooth UART fixes it already carried.
- Code Aurora Forum / Qualcomm: the MSM8994 kernel, msm_thermal (KTM), BCL
  and the default KTM limits.

Audio (speaker, earpiece, calls)
--------------------------------
- EpicLPer (Android4Lumia950, talkman): the TAS2552/TAS2553 speaker
  amplifier driver and the Quaternary MI2S wiring (e4d0c025066,
  9bd1bb032d4, 22039ccd1ea, 5b52570b88d), and the AP-side sensor I2C buses
  (7d96420fc1e).
- shadowofleaf96 (github.com/shadowofleaf96/android_kernel_msft_cityman):
  the cityman Q6 MI2S node, the unused WCD9330 speaker supplies and the
  ASM open without an ACDB topology (efb1ebf, 1a51144), the MSM8994 eMMC
  clock rates (4bc7ab2), the sensor and NFC includes for cityman (cd01dc9,
  386e7a0) and the nq-nci resume fix (628c06f).

Eight cores and thermal protection
----------------------------------
- Huawei/Google, angler (Nexus 6P) and LineageOS, OnePlus 2
  (LineageOS/android_kernel_oneplus_msm8994): the MSM8994 KTM limits and the
  eight-core bring-up order used as reference.
- Sony (sonyxperiadev, Kitakami): the A53/A57 sensor map and the A57 steps
  used as reference.
- shadowofleaf96: the only other cityman port running eight cores, used for
  comparison; nothing of it is copied here.

Crash logs (pstore)
-------------------
- hraj9258 (Himanshu Raj) and sonic011gamer
  (github.com/hraj9258/android_kernel_mmo_msm8994, talkman-cam-clean):
  the ramoops region at the top of DDR bank 1 and the pmsg bounce buffer
  allocated once (b32f68bcb4b, cherry-picked as is). On cityman the board
  override that moved ramoops elsewhere is dropped so it uses that region.

USB FunctionFS AIO (Android 16 adbd)
------------------------------------
- Robert Baldyga (Samsung): "usb: gadget: f_fs: add aio support", Linux 3.15.
- acroreiser (Yaroslav Zviezda): the 3.10 backport (46b42fd0e68 in this tree,
  later reverted in 1b47b1a8025), also used by davigamer987 on
  kernel_oneplus_msm8994 lineage-23.2 (c3e9d413d72, ep0 poll f9c17d5e0d7),
  the working Android 16 reference on MSM8994. The port here is rewritten on
  the current f_fs.c.
- djokcho (73fe86913b4: ep0 poll, preallocated buffers) and sonic011gamer
  (7df9f0a10d0: no_disconnect, v1+SS descriptors), Android4Lumia950.

Camera (rear lens and ION)
--------------------------
- hraj9258 (Himanshu Raj, github.com/hraj9258/android_kernel_mmo_msm8994,
  talkman-cam-clean): ACTUATOR_VCM_BE for the rear lens controller, which
  takes the high byte of the position first (01d0093, here with the enum it
  needs from bb9466c), and the ION mapping guard page (0259b10).

Double tap to wake (touch controller)
-------------------------------------
- WOA-Project/SynapticsTouch (github.com/WOA-Project/SynapticsTouch;
  Bingxing Wang and the LumiaWoA authors, on the Microsoft sample driver):
  the F12 CTRL20 byte 2 sequence (0x02 screen off, 0x00 screen on) and the
  F12 DATA4 double tap code (0x03) on the Lumia 950 XL, src/power.c and
  src/rmi4/f12/function12.c. The double tap timing (350 ms, 3 mm) and the
  controller reset on wake come from the Microsoft Windows driver package
  of the 950 XL (cityman_SynapticsTouch.inf).
- Synaptics DSX 2.5 (Synaptics Inc.) as shipped in the Nexus 6P kernel
  (github.com/Android4Lumia950/angler-1, android-msm-angler-3.10,
  drivers/input/touchscreen/synaptics_dsx25/synaptics_dsx_core.c): the
  CTRL20/CTRL27/DATA4 offsets from the F12 query 5 and query 8 bitmaps,
  the KEY_WAKEUP report and the wake interrupt handling.
- OnePlus and LineageOS (github.com/LineageOS/android_kernel_oneplus_msm8994,
  lineage-18.0, synaptics_driver_s3320.c): gesture enable through CTRL20 on
  another MSM8994 phone, as a reference for the suspend/resume sequence.

Not in this branch
------------------
- archienz (github.com/archienz/android_kernel_mmo_msm8994): rear camera
  measurements on the Lumia 950 (CSI lane map 0x0423, 24 MHz MCLK), used on
  the lineage-18.1-cityman-camera branch.
- hraj9258 (github.com/hraj9258/android_kernel_mmo_msm8994,
  talkman-cam-clean): the rest of the talkman rear camera bring-up (kernel
  SMIA++ sensor driver, CSID/ISP changes, Hill flash), under evaluation.
